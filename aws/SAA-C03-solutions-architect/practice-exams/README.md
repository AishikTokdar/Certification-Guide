# SAA-C03 Practice Exams

This directory indexes the 515-question scenario bank and readiness benchmarks for the AWS Certified Solutions Architect - Associate (SAA-C03) exam.

---

## Primary 515-Question Scenario Bank (PDF)

All 515 original exam-style questions (with full explanations for correct choices and distractors) are consolidated in:

- **[`pdfs/04_AWS_SAA-C03_Practice_Question_Bank.pdf`](../pdfs/04_AWS_SAA-C03_Practice_Question_Bank.pdf)** (246 pages, Volumes 1–7)

### Question Bank Distribution Across Volumes

| Volume | Question Range | Count | Focus & Role |
| :---: | :---: | :---: | :--- |
| Volume 1 | Q1 – Q80 | 80 | Core cross-domain baseline (Domain 1–4 proportional weights) |
| Volume 2 | Q81 – Q180 | 100 | New architectural scenarios, zero topic overlap with Volume 1 |
| Volume 3 | Q181 – Q280 | 100 | Deeper multi-constraint scenarios across all 4 domains |
| Volume 4 | Q281 – Q391 | 111 | Advanced hybrid networking, storage, and cost optimization |
| Volume 5 | Q392 – Q414 | 23 | Targeted edge-case scenarios completing primary weights |
| Volume 6 | Q415 – Q476 | 62 | **Gap Closer Set A**: Scenarios written specifically against all official guide v1.1 bullets |
| Volume 7 | Q477 – Q515 | 39 | **Gap Closer Set B**: Second-angle questions for thin-coverage services (AWS Proton, Data Pipeline, EKS Distro) |
