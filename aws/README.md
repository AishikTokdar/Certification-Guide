## Active Guide 1: AWS Certified AI Practitioner (AIF-C01)

The complete study package for AIF-C01 is available in [**AIF-C01-ai-practitioner/**](AIF-C01-ai-practitioner/):

- **Curated PDF Collection**: 5 standardized PDFs covering official exam guide, comprehensive notes (Mohammed Abdullah Khan), cheat sheet, gap-closer addendum, and a 200-question practice bank.
- **Official Exam Blueprint**: Scraped domain task statements, in-scope service specifications, and test outlines from AWS Certification documentation.
- **Technical Study Notes**: Domain-by-domain markdown guides covering Bedrock, SageMaker, pre-built AI services, and Responsible AI.
- **Practice Test Suite**: 7 full markdown practice test sets with solutions.
- **Resources Catalog**: Complete reference list of AWS official documentation, Skill Builder courses, and open-source study repositories.

## Active Guide 2: AWS Certified Solutions Architect - Associate (SAA-C03)

The complete study package for SAA-C03 is available in [**SAA-C03-solutions-architect/**](SAA-C03-solutions-architect/):

- **Curated PDF Collection**: 7 standardized PDFs covering the official AWS v1.1 exam guide, complete exam notes (Mohammed Abdullah Khan), rapid cheat sheet & decision rules, syllabus coverage & 12-lab readiness audit, 515-question practice bank, Tutorials Dojo study guide (Jon Bonso), and Notion visual notebook (Christian Greciano).
- **Official Exam Blueprint**: AWS v1.1 domain task statements (1.1–4.4), technologies and concepts, short-name guidelines, and in-scope/out-of-scope service lists.
- **Modular Topic Guides**: 37 exam-focused topic guides (`study-notes/topic-guides/`) adapted from `RonitSachdev/aws-saa-c03-guides` under CC BY 4.0.
- **Practice Bank Overview**: Indexed 515-question bank across Volumes 1–7 (`practice-exams/`) with pacing benchmarks and readiness targets.
- **Resources Catalog**: Direct links to AWS architecture whitepapers, Well-Architected pillars, and service user guides.
